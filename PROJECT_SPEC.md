# Product specification

Media Workbench serves a trusted operator assembling sequential video segments with optional source audio. Asset intake probes stream metadata and records a content hash. A project owns an ordered timeline of clips referencing assets; clip endpoints use integer milliseconds and gain is bounded to 0–2. A render freezes the current project revision, validates source integrity, normalizes video and audio, concatenates the segments and publishes a new MP4 without replacing an existing file. SQLite records running, completed and failed renders. Missing audio is represented by silence. The service exposes JSON endpoints documented in README. The output is fixed at 640×360, 25 fps, stereo 48 kHz. Errors are returned as JSON. Tests are deliberately deferred; bounded media processing and output inspection are the initial verification boundary.
